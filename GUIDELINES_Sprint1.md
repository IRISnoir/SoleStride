# Sprint 1 — API Endpoint & Component Overview

## Epic: E01 — Quản lý tài khoản & Phân quyền (US01–US07)

### Controller & Actions (API Endpoint / Component chính)

| Controller | Action | Method | Description | Related Tasks |
|---|---|---|---|---|
| `AccountController` | `Register` | GET | Hiển thị form đăng ký — trả về view `Register.cshtml` | Thiết kế giao diện đăng ký |
| `AccountController` | `Register` | POST | Nhận dữ liệu từ form (Username, Password, Email, Phone, Birthdate, Gender), validate với Data Annotations, hash password bằng SHA256, tạo mới User trong DB bằng EF Core, redirect về Login | Xây dựng API đăng ký tài khoản |
| `AccountController` | `Login` | GET | Hiển thị form đăng nhập — trả về view `Login.cshtml` | Thiết kế giao diện đăng nhập |
| `AccountController` | `Login` | POST | Nhận username + password, tìm user trong DB, hash password so sánh, nếu đúng tạo session (`SetString("Username", ...)`, `SetString("Role", ...)`), redirect về Home/Index | Xây dựng API đăng nhập, Lưu phiên đăng nhập (Session) |
| `AccountController` | `Logout` | GET | Xóa toàn bộ session (`HttpContext.Session.Clear()`), redirect về Home/Index | Xây dựng chức năng đăng xuất, Xóa Session |

### Frontend Components / Views

| View/Component | Location | Description | Related Tasks |
|---|---|---|---|
| `Register.cshtml` | `Views/Account/Register.cshtml` | Form đăng ký với các field: Username, Password, Confirm Password, Email, Phone, Birthdate, Gender. Dùng `asp-action="Register"`, `asp-for` tag helpers cho từng input, hiển thị `ValidationSummary` và `ValidationMessageFor` cho từng field | Thiết kế giao diện đăng ký |
| `Login.cshtml` | `Views/Account/Login.cshtml` | Form đăng nhập với 2 field: Username, Password. Dùng `asp-action="Login"`, hiển thị `ViewBag.Error` nếu đăng nhập thất bại | Thiết kế giao diện đăng nhập |
| `_Layout.cshtml` | `Views/Shared/_Layout.cshtml` | Shared layout — chứa navbar với link Đăng nhập/Đăng xuất (hiển thị conditional dựa trên session `Username`), menu danh mục | Thiết kế giao diện đăng ký, đăng nhập |

### Model & Database

- **Model:** `User` (`SoleStride.Models.User`)
  - `Username` (string, PK, max 100)
  - `Password` (string, hashed SHA256)
  - `Role` (enum: Admin, Staff, User)
  - `Phone` (string, optional)
  - `EmailAddress` (string, optional, `[EmailAddress]` validation)
  - `Birthdate` (DateTime)
  - `UserGender` (enum: Male, Female, Other)
- **DB Table:** `Users` — auto-generated by EF Core migration
- **Validation:** Data Annotations (`[Required]`, `[EmailAddress]`, `[Phone]`, `[MaxLength(100)]`)

### Task Mapping

| Task | US | Type | Chi tiết công việc |
|---|---|---|---|
| Thiết kế giao diện đăng ký | US01 | Frontend (View) | Tạo `Register.cshtml` với form đầy đủ field (Username, Password, Confirm Password, Email, Phone, Birthdate, Gender), dùng Bootstrap cho styling, thêm client-side validation |
| Thiết kế Database (bảng Users) | US01 | Model/Migration | Đảm bảo model `User` đã có đầy đủ fields, tạo migration `Add-Migration AddUsersTable`, chạy `Update-Database` |
| Xây dựng API đăng ký tài khoản | US01 | Controller Action | Viết `POST Register` trong `AccountController`: nhận User từ form, validate ModelState, hash password SHA256, `_context.Users.Add(user)`, `_context.SaveChangesAsync()`, redirect đến Login |
| Kiểm thử chức năng đăng ký | US01 | QA | Test đăng ký thành công (user mới vào DB), test validation (thiếu field, email sai format, username trùng) |
| Thiết kế giao diện đăng nhập | US02 | Frontend (View) | Tạo `Login.cshtml` với form Username + Password, hiển thị `ViewBag.Error` khi đăng nhập thất bại |
| Xây dựng API đăng nhập | US02 | Controller Action | Viết `POST Login` trong `AccountController`: nhận username/password, tìm user trong DB, hash password so sánh, tạo session `SetString("Username", ...)` + `SetString("Role", ...)`, redirect về Home |
| Lưu phiên đăng nhập (Session) | US02 | Session | Session lưu `Username` và `Role` — dùng để hiển thị thông tin user trên `_Layout.cshtml` và kiểm soát quyền truy cập |
| Kiểm thử chức năng đăng nhập | US02 | QA | Test đăng nhập thành công (session được tạo), test sai username/password (hiển thị lỗi), test session tồn tại sau khi đăng nhập |
| Xây dựng chức năng đăng xuất | US03 | Controller Action | Viết `Logout` trong `AccountController`: gọi `HttpContext.Session.Clear()`, redirect về Home/Index |
| Xóa Session | US03 | Session | `Session.Clear()` xóa tất cả session variables, đảm bảo user không còn đăng nhập sau khi logout |
| Kiểm thử chức năng đăng xuất | US03 | QA | Test logout xóa session, kiểm tra redirect về Home, kiểm tra không còn truy cập trang auth khi chưa login |

## Epic: E02 — Danh mục sản phẩm & Khuyến mãi (US08–US09)

### Controller & Actions (API Endpoint / Component chính)

| Controller | Action | Method | Description | Related Tasks |
|---|---|---|---|---|
| `CategoryController` | `Index` | GET | Lấy danh sách tất cả categories từ DB (`_context.Category.ToListAsync()`), trả về view `Index.cshtml` | Thiết kế giao diện xem danh mục |
| `CategoryController` | `Details` | GET | Tìm category theo `categoryid` (string), trả về view `Details.cshtml` hiển thị thông tin category | Xem chi tiết danh mục |
| `CategoryController` | `Create` | GET | Trả về view `Create.cshtml` với form trống | Thiết kế giao diện tạo danh mục |
| `CategoryController` | `Create` | POST | Nhận Category từ form, validate, thêm vào DB, redirect về Create | Xây dựng logic tạo danh mục |
| `CategoryController` | `Delete` | GET/POST | Xác nhận xóa category, xóa khỏi DB, redirect về Create | Xóa danh mục |
| `ShoesController` | `Index` | GET | Lấy danh sách tất cả shoes từ DB (`_context.Shoes.ToListAsync()`), trả về view `Index.cshtml` | Xây dựng logic xem các sản phẩm |
| `ShoesController` | `Details` | GET | Tìm shoes theo `productid` (Guid), bao gồm cả `Category` navigation property, trả về view `Details.cshtml` hiển thị ảnh, tên, giá, mô tả, size, color, category, sale percentage | Cập nhật với logic xem chi tiết |
| `ShoesController` | `Create` | GET | Trả về view `Create.cshtml` với form thêm sản phẩm (có dropdown category, upload ảnh) | Thiết kế giao diện xem chi tiết |
| `ShoesController` | `Create` | POST | Nhận Shoes + IFormFile imageFile, validate, auto-generate SKU, lưu ảnh vào `wwwroot/images/`, set `ImageUrl`, thêm vào DB, redirect về Home/Index | Thiết kế giao diện xem chi tiết |
| `ShoesController` | `Edit` | GET | Tìm shoes theo `productid`, trả về view `Edit.cshtml` với dữ liệu hiện tại | Cập nhật với logic xem chi tiết |
| `ShoesController` | `Edit` | POST | Cập nhật shoes trong DB, save changes, redirect về Index | Cập nhật với logic xem chi tiết |
| `ShoesController` | `Delete` | GET/POST | Xác nhận xóa shoes, xóa khỏi DB, redirect về Index | Xóa sản phẩm |

### Frontend Components / Views

| View/Component | Location | Description | Related Tasks |

| `Details.cshtml` (Category) | `Views/Category/Details.cshtml` | Hiển thị chi tiết 1 danh mục: CategoryId, CategoryName | Xem chi tiết danh mục |

| `Index.cshtml` (Shoes) | `Views/Shoes/Index.cshtml` | Grid danh sách sản phẩm — hiển thị ảnh, tên, giá, category, nút Details/Edit/Delete | Thiết kế giao diện xem danh mục |
| `Details.cshtml` (Shoes) | `Views/Shoes/Details.cshtml` | Đã có sẵn từ scaffold — chỉ cần chỉnh sửa layout, thêm ảnh lớn, sale badge, category name | Thiết kế giao diện xem chi tiết |
| `Create.cshtml` (Shoes) | `Views/Shoes/Create.cshtml` | Đã có sẵn từ scaffold — chỉ cần thêm field Category (dropdown từ DB), upload ảnh (IFormFile) | Thiết kế giao diện xem chi tiết |
| `_Layout.cshtml` | `Views/Shared/_Layout.cshtml` | Shared layout — navbar với menu danh mục (link đến Category/Index), hiển thị session username nếu đã đăng nhập | Thiết kế giao diện xem danh mục |

### Model & Database

- **Model:** `Category` (`SoleStride.Models.Category`)
  - `CategoryId` (string, PK, max 10)
  - `CategoryName` (string, max 100, `[Required]`)
- **Model:** `Shoes` (`SoleStride.Models.Shoes`)
  - `ProductId` (Guid, PK)
  - `ShoesName` (string, max 100, `[Required]`)
  - `SkuId` (string, auto-generated from CategoryId + Gender + Size + Color)
  - `CategoryId` (string, FK → Category.CategoryId)
  - `Category` (navigation property)
  - `ShoesGender` (enum: Men, Women, Unisex)
  - `ShoesSize` (int)
  - `ShoesColor` (string)
  - `Material` (string)
  - `Description` (string, optional)
  - `Price` (decimal, `[Required]`)
  - `SalePercentage` (float, 0–100, optional)
  - `ImageUrl` (string, optional)
- **DB Tables:** `Categories`, `Shoes` — auto-generated by EF Core migration
- **Image Upload:** Saved to `wwwroot/images/`, path stored in `Shoes.ImageUrl`
